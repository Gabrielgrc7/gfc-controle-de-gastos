# Segurança

Para avisar sobre uma falha de segurança, escreva para o e-mail do encarregado de dados (o mesmo que está em `CFG`, em `src/js/core/config.js`).
Não abra uma "issue" pública com detalhes de uma falha antes de ela ser corrigida.
Nunca coloque no GitHub: senhas, chaves de API, faturas, extratos ou qualquer dado pessoal real.
